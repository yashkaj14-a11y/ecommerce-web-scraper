# E-Commerce & Web Scraping Script

A simple and robust Python script using `BeautifulSoup` and `Pandas` to extract structured data from web pages into CSV format.

### Features
- Fetches HTML content cleanly using `requests`
- Parses elements with `BeautifulSoup`
- Saves structured dataset automatically to `CSV`

### Tech Stack
- Python 3.x
- BeautifulSoup4
- Pandas
